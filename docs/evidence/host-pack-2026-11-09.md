# Host evidence pack — home server (sanitized copy)

**Provenance:** supplied by the owner on 2026-11-09 as pasted text. Captured on the host with `lscpu`, `/proc`, `/sys`, `dmidecode`, `lshw`, `rdmsr` (root), `systemd-detect-virt`. I did not run these commands; I have no access to the host. Every value below is **owner-reported**, not independently verified.

**Sanitization (public repo):** removed hostname, the owner's username, the client IP, other users' account names, their job command lines and the telemetry endpoint they push to. Kept: all hardware/firmware/kernel facts and aggregate co-tenancy counts. The unredacted pack stays with the owner. Rule going forward: **no other person's identifiers or internal endpoints go into this repo** (see D-27).

Host label used in this repo: **HOST-A**.

## H1 — CPU
- Intel Core i7-12700 (Alder Lake, family 6 model 151 / 0x97 stepping 2), 1 socket, 12 cores / 20 threads (8 P-cores with SMT + 4 E-cores), x86_64.
- Virtualization: VT-x. Flags: `vmx ept vpid ept_ad vnmi flexpriority invpcid_single pcid x2apic`; `tsc rdtscp constant_tsc nonstop_tsc tsc_known_freq tsc_adjust art`; `smep smap pku ospke avx2 avx_vnni bmi1 bmi2 aes sha_ni rdseed`. `svm`, `tdx`, `sev*`, `snp`, `sme`: absent.
- Frequencies: max 4900 MHz, min 800 MHz. L1d 512 KiB (12 inst.), L1i 512 KiB, L2 12 MiB (9 inst.), L3 25 MiB (1 inst.), 1 NUMA node.
- Topology (`lscpu -e`): CPU 0–15 = P-cores 0–7 (2 threads each, max 4800–4900 MHz); CPU 16–19 = E-cores 8–11 (1 thread each, max 3600 MHz).
- Clock: `current_clocksource=tsc`, available `tsc hpet acpi_pm`, external clock 100 MHz. Boot-time dmesg unavailable (ring buffer rotated, uptime 74 d).
- Boot cmdline: `BOOT_IMAGE=/vmlinuz-5.15.0-190-generic root=/dev/mapper/ubuntu--vg-ubuntu--lv ro nomodeset quiet splash isolcpus=2 nohz_full=2 rcu_nocbs=2 vt.handoff=7` → **CPU 2 isolated** (scheduler, tick, RCU callbacks).
- Active vulnerability mitigations (affect absolute timing): Spectre v1; Spectre v2 (Enhanced/Auto IBRS + BHI_DIS_S); Spec store bypass; Reg file data sampling; **Vmscape (IBPB before exit to userspace)**.

## H2 — Memory
- 128 GiB total (MemTotal 131,570,840 kB ≈ 125.5 GiB), non-ECC DDR5, 4 × 32 GB DIMMs (G.Skill F5-5200J3636D32G), dual channel / 2 DIMMs per channel, running 4800 MT/s (XMP off; kit rated 5200), 1.35 V.
- At capture: used 4.0 GiB, free 76 GiB, buff/cache 45 GiB, available 116 GiB; shared 2.9 GiB. Swap 8 GiB (373 MiB used). HugePages_Total 0, Hugepagesize 2048 kB, AnonHugePages 0.

## H3 — Platform, privileges, kernel
- `systemd-detect-virt` = `none` (exit 1); hypervisor CPU flag absent; DMI consistent with real hardware.
- Board: Micro-Star MS-7E07 PRO Z790-A WIFI (desktop, chassis type 3); BIOS AMI A.90 dated 2024-01-10; Secure Boot disabled; microcode 0x3e; **no BMC/IPMI** (BIOS changes need physical access).
- Privileges: member of `sudo` and `kvm`; `sudo` needs a password (held by the owner); NOPASSWD only for `tee /proc/sys/vm/drop_caches`. `/dev/kvm` usable; `kvm_intel` loaded with `nested=Y`; modules `kvm kvm_intel vhost vhost_iotlb vhost_net vhost_vsock`.
- OS/kernel: Ubuntu 22.04.5 LTS, `Linux 5.15.0-190-generic #200-Ubuntu`, uptime 74 d. Installed kernels 5.15.0-190, -191, -202 (running image is not the newest → **a reboot is already pending**). `linux-image-generic-hwe-22.04` candidate = 6.8.0-138 (not installed).
- MSR read-outs (root): `MSR_PLATFORM_INFO 0xCE = 0x08040838F0811500` (max non-turbo ratio 21 → 2100 MHz; efficiency ratio 8 → 800 MHz); `MSR_TURBO_RATIO_LIMIT 0x1AD = 0x2D2D2E2E2F2F3031` (1…8 active cores: 4.9 / 4.8 / 4.7 / 4.7 / 4.6 / 4.6 / 4.5 / 4.5 GHz); `IA32_MISC_ENABLE` turbo_disable bit = 0 (**turbo enabled**); `MSR_PKG_CST_CONFIG_CONTROL 0xE2 = 0x74008000` (package C-state limit C0, **CFG Lock = 1**); `IA32_POWER_CTL 0x1FC = 0x00F80059`; `IA32_TEMPERATURE_TARGET 0x1A2 = 0x641400` (TjMax 100 °C).
- cpuidle exposes only POLL, C1_ACPI (latency 1), C2_ACPI (latency 127). cpufreq: `intel_pstate`, governor `powersave`, `no_turbo=0`. Live ratios at capture: P 45× (4500 MHz), E 34× (3400 MHz).
